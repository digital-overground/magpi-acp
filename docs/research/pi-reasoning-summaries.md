# Pi reasoning-summary controls (installed Pi 0.87.1)

- OpenAI's Responses API accepts `reasoning: { effort, summary }`; `summary: "concise"` requests a shorter **visible summary**, not less private reasoning. Model support varies. [OpenAI reasoning guide](https://developers.openai.com/api/docs/guides/reasoning#reasoning-summaries)
- Codex exposes `model_reasoning_summary = "concise"` in its **own** config. This is not a Pi setting. [Codex configuration reference](https://developers.openai.com/codex/config-reference)
- Pi's installed OpenAI Responses provider accepts an internal `reasoningSummary` option and otherwise builds `reasoning: { effort, summary: "auto" }` when effort is enabled. Its Codex subscription provider similarly defaults to `"auto"` when effort is set. Both emit API reasoning-summary events as thinking deltas. Sources: installed `dist/bundle/chunks/openai-responses-HWEUZ6WZ.js`, `openai-codex-responses-QDSOTBBO.js`, `chunk-WIUZI2CJ.js` in `/opt/homebrew/lib/node_modules/@earendil-works/pi-coding-agent/`.
- Pi's documented `settings.json` thinking control is **effort**, not summary length. Pi's `models.json` can override `samplingParams`, but the installed Codex subscription request builder does not use `samplingParams`; setting it there would not fix that route. Sources: [Pi settings](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/settings.md), installed `dist/core/model-config.js`, `dist/bundle/chunks/openai-codex-responses-QDSOTBBO.js`.
- A Pi extension can override the outgoing payload via `before_provider_request`, including setting `reasoning.summary` to `"concise"` while retaining `reasoning.effort`. This applies to the normal Pi runtime (including RPC), without changing MagPi ACP or Codex config. Sources: installed `dist/core/sdk.js`, `dist/core/extensions/types.d.ts`, and [Pi's payload-extension example](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/examples/extensions/provider-payload.ts).
- MagPi ACP forwards Pi's `thinking_delta` unchanged as ACP `agent_thought_chunk`: [`src/acp/magpi-session.ts`](../../src/acp/magpi-session.ts).
