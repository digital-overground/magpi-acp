# Plan: request concise OpenAI reasoning summaries from Pi

Goal: MagPi's Pi subprocess requests `reasoning.summary: "concise"` instead of Pi's current `"auto"`, without reducing `reasoning.effort` or rewriting the text after it arrives. Applies to MagPi-launched Pi sessions only; no change to standalone Pi or Mischief.

1. Add `src/pi-extension/concise-reasoning.ts`, following the existing bundled Pi extension pattern. Register `pi.on("before_provider_request", (event, ctx) => ...)`. For OpenAI Responses models (`ctx.model?.api` of `openai-responses` or `openai-codex-responses`), inspect the outgoing payload. Only when `payload.reasoning` is an object, its `effort` is enabled, and its `summary` is `"auto"`, return a payload with `reasoning.summary` set to `"concise"`. Leave effort, `include`, every other field, and explicitly chosen summary values untouched. Never opt in to thinking when it is off. Guard against non-object payloads and other provider APIs.
2. Add the extension to `tsup.config.ts` and to `bundledExtensionPaths()` in `src/pi-rpc/process.ts` so development (`src/pi-extension/*.ts`) and published (`dist/pi-*-extension.js`) runs both load it via `--extension`. No new dependency, settings format, or ACP message translation.
3. Extend `test/unit/pi-rpc-extensions.test.ts` to expect the third bundled extension. Add one small unit test that invokes the registered hook with `reasoning: { effort: "high", summary: "auto" }` and verifies `"concise"` with unchanged effort; also check off, non-OpenAI, and explicitly configured summaries pass through. Keep the test offline: no provider credentials or network requests needed.
4. Format touched files; run `npm run check` and `npm run smoke`. If a real-provider check is desired afterward, inspect an outgoing request through Pi's existing `before_provider_request` hook and confirm `reasoning.summary` is `"concise"` while the selected effort stays the same. Do not log credentials or whole payloads.

Why an extension: the installed Pi 0.87.1 already builds `reasoning.summary: "auto"` for both OpenAI API and Codex subscription routes and provides this payload hook, but has no documented summary-length setting. MagPi already bundles two Pi extensions and forwards thinking deltas unchanged. See [research notes](research/pi-reasoning-summaries.md).
